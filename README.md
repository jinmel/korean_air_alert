# 대한항공 보너스 좌석 월별 조회

Python 3.10 이상에서 표준 라이브러리만으로 실행합니다. 브라우저, Playwright,
추가 pip 패키지는 필요하지 않습니다. 공개 현황 조회는 비로그인으로 가능하며,
실제 예매 검색 재확인에는 환경 변수로 전달한 로그인 정보가 필요합니다.

시작 월부터 한국 시간 오늘 + 360일까지 월별로 조회하여 프레스티지석 보너스(O),
일등석 보너스(A)를 출력합니다. 승급(Z 등)은 제외합니다.
문서화된 공식 외부 공개 API가 아니라 공식 웹사이트의 조회 API를 이용합니다.

```bash
# 이번 달부터 조회 한도까지
python korean_award.py --origin ICN --destination JFK

# 시작 월 변경: 해당 월부터 조회 한도까지
python korean_award.py --origin ICN --destination JFK --month 2027-01

# 시작 월과 종료 월 지정
python korean_award.py --origin ICN --destination JFK --month 2027-01 --until 2027-03

# 반대 방향
python korean_award.py --origin JFK --destination ICN
```

## 동작 방식

1. Python urllib로 공식 보너스 좌석 조회 페이지를 열어 HTTP 세션을 초기화합니다.
2. CookieJar가 서버의 쿠키를 메모리에 보관하고 이후 요청에 전달합니다.
3. 동일한 세션으로 다음 API에 월별 POST 요청을 보냅니다.

```text
https://www.koreanair.com/api/hmp/bonusSeatView/bonusSeatView
```

```json
{"arrivalAirport": "JFK", "departureAirport": "ICN", "departureDate": "20270101"}
```

User-Agent는 `KoreanAwardChecker/1.0 (Python urllib)`입니다. 웹사이트 요청에 쓰이는
Origin, Referer, channel 등의 헤더를 포함하며 JavaScript나 브라우저 엔진을 실행하지 않습니다.
브라우저 쿠키 복사, 브라우저 식별값 위장, CAPTCHA 해제, 프록시 순환은 사용하지 않습니다.
실행 환경의 프록시 및 TLS 인증서 검증 설정은 기본값을 따릅니다.

## 범위 및 오류 처리

- 노선 하나의 편도 조회입니다. 반대 방향은 공항 코드를 바꾸어 실행하세요.
- `--month` 기본값은 한국 시간 이번 달입니다. 과거 날짜는 출력하지 않습니다.
- `--until` 생략 시 한도까지 조회합니다. `--days` 기본값은 360입니다.
  이 값을 키워도 서버의 조회 가능 범위가 늘어나는 것은 아닙니다.
- 미래 월을 시작 월로 선택해도 한도는 실행일 기준입니다.
- 월별 요청 사이에 2초 간격을 둡니다. 오류나 차단이 있으면 중단하며 재시도하지 않습니다.
- 미인식 응답, 날짜 누락, 요청과 다른 월/노선, 빈 항공편 목록은 조회 실패로 처리합니다.
  미운항 노선/월도 성공으로 판정하지 못할 수 있습니다.
- 403이나 인증 요구를 좌석 없음으로 해석하지 않습니다. 쿠키와 요청 헤더는 파일에 저장하지 않습니다.
- 공개 현황은 공식 화면 안내상 일 1회 업데이트됩니다. 실시간 예약 가능 여부나 좌석 수가 아닙니다.
- 비공식 API의 요청 구조나 접근 정책이 바뀌면 수정이 필요할 수 있습니다.

## 실제 검증

2026-10-27 한국 시간, 현재 클라우드 환경에서 브라우저 없이 다음 명령으로 검증했습니다.

```bash
python -m unittest -v
python korean_award.py --origin ICN --destination JFK
python korean_award.py --origin ICN --destination JFK --month 2027-01 --until 2027-01
```

- 테스트 10개 통과: 날짜 범위/승급 제외, HTTP 세션 쿠키 유지, 월 변경,
  403·HTML 응답·잘못된 월/노선 거부.
- ICN → JFK, 2026-10-27 ~ 2027-10-22, 13개월 월별 조회 완료(종료 코드 0).
- 프레스티지 보너스 표시: 2026-10-27 KE081, 2027-10-22 KE081/KE085, 총 3건.
- 위 조회에서 일등석 보너스 표시는 없었습니다. 건수는 좌석 수가 아닙니다.
- 시작 월을 2027-01로 지정한 단일 월 조회도 완료했습니다(종료 코드 0).
- 이전 공식 화면에서 확인한 현황 기준 시각은 2026-10-26 23:00 KST입니다.

검증은 위 노선 및 실행 시점에 한정됩니다. 최종 예약 가능 여부는 예매 화면에서 확인하세요.

## 실제 예매 검색 재확인 (`--verify-live`)

공개 현황에서 발견한 후보를 로그인한 본인 성인 1명의 편도 예매 검색으로 다시 조회합니다.
공개 현황에 없는 날짜까지 실시간으로 전수 검색하는 기능은 아닙니다.
브라우저 및 추가 패키지는 필요하지 않습니다.

환경 변수로 로그인 정보를 전달합니다. 비밀번호를 명령줄 인수나 소스 파일에 넣지 마세요.
Bash에서는 다음처럼 터미널에서 입력하면 실제 값이 명령 기록에 남지 않습니다.

```bash
read -r -p '대한항공 ID: ' KOREANAIR_USERNAME
read -r -s -p '비밀번호: ' KOREANAIR_PASSWORD
printf '\n'
export KOREANAIR_USERNAME KOREANAIR_PASSWORD

python korean_award.py --origin ICN --destination JFK --verify-live

unset KOREANAIR_USERNAME KOREANAIR_PASSWORD
```

- `KOREANAIR_USERNAME`: 대한항공 홈페이지 ID.
- `KOREANAIR_PASSWORD`: 해당 계정의 비밀번호. 앞뒤 공백 등 원문을 변경하지 않습니다.
- `KOREANAIR_LOGIN_TYPE`: 기본 `id`. 스카이패스 번호로 로그인하려면 `skypass`로 설정하고
  `KOREANAIR_USERNAME`에 스카이패스 번호를 넣으세요. 소셜 로그인은 지원하지 않습니다.
- `--verify-live` 없이 실행하면 환경 변수와 무관하게 로그인하지 않습니다.
- 로그인 실패 시 재시도하지 않습니다. CAPTCHA/추가 인증이 필요하면 미확인 상태로 종료합니다.
- 로그인 정보와 회원 정보, 쿠키, 응답 원문을 파일이나 로그에 저장하지 않습니다.
- 본인 영문 이름·스카이패스 번호는 로그인 응답에서 읽어 메모리에서만 사용합니다.

로그인은 `/api/li/auth/signIn`, 예매 검색은
`/api/ap/booking/avail/awardAvailability`를 사용합니다. 요청 형식은 공식 웹사이트가
배포하는 JavaScript의 로그인 서비스 및 `getAwardAvailabilityParam`에서 확인했습니다.
예매 검색은 `commercialFareFamilies: ["KEBONUSNEW"]`, 편도 구간, 본인 성인 1명으로 요청합니다.
동일 날짜의 다른 항공편/등급은 응답을 재사용하여 중복 검색을 줄입니다.

결과는 다음처럼 구분합니다.

- **예매 검색에서 선택 가능**: 동일 날짜·노선·직항 편명에서 요청한 보너스 운임
  (`KEBONUSPR`/O 또는 `KEBONUSFC`/A), 양수 좌석 수, 선택 식별자를 확인한 경우.
- **예매 검색에서 선택 불가**: 해당 운임의 좌석 수가 0 또는 빈 문자열이거나 매진으로 표시된 경우.
- **미확인**: 항공편/운임을 찾지 못했거나 응답 형식을 확인할 수 없는 경우. 좌석 없음이 아닙니다.
- **조회 실패**: 인증·네트워크 오류 등으로 검색하지 못한 경우. 이후 검증을 중단합니다.

선택 가능은 검색 시점의 상태이며 최종 발권 보장이 아닙니다. 좌석 확보, 예약 생성,
운임 확정, 마일리지 차감, 결제를 수행하지 않습니다. 실제 응답의 좌석 수는 항공사의 전체 재고와 다를 수 있습니다.

### 실시간 검증 기능의 검증 범위

2026-10-27 한국 시간에 실제 계정으로 로그인 및 예매 검색을 검증했습니다.
자격 증명은 비표시 터미널 입력으로 받아 프로세스 환경 변수로만 전달했고 저장하지 않았습니다.
로그인 요청에는 공식 사이트와 동일하게 세션 ID(`ksessionId`)와 요청 시각(`timestamp`)을 포함합니다.
세션 ID는 실행마다 새로 만들고 같은 클라이언트의 요청에서 유지합니다.

- 공식 현황 API: ICN → JFK, 13개월 조회 완료, 프레스티지 후보 3건.
- 실제 로그인 성공 및 본인 성인 1명의 예매 검색 성공.
- 2027-10-22 KE081/KE085: 프레스티지 보너스 운임의 `seatCount="0"`, `soldout=true` 확인.
  공개 현황의 표시와 달리 실제 검색에서는 모두 선택 불가였습니다(09:28 KST 확인).
- 2026-10-27 KE081: 실제 검색 응답에서 항공편을 찾지 못하여 미확인으로 처리했습니다.
- 실제 양수 좌석이 있는 응답은 이 검증에서 발견하지 못했습니다. 선택 가능 판정은 모의 응답으로 테스트했습니다.
- 로그인 HTTP 오류는 상태 코드만 표시하고 응답 원문이나 자격 증명을 출력하지 않습니다.

로컬 HTTP 서버 테스트로 환경 변수 로그인, 세션 ID·쿠키 유지, 검색 요청,
403 상태 진단과 비밀정보 비노출, 날짜/노선/등급 일치 및 매진/미확인 구분을 확인합니다.
이 검증은 해당 실행 시점·계정·노선에 한정되며, 항공사의 접근 정책과 응답 구조가 바뀌면 수정이 필요할 수 있습니다.

## 추가 확인 도구

프로젝트 루트에서 실행합니다. 환경 변수가 없으면 로그인 정보를 비표시 터미널 입력으로 받습니다.

```bash
# 내일·7일 후·30일 후·360일 후 순서로 일반석 보너스를 검색하고 첫 선택 가능 날짜를 출력
python examples/check_economy.py

# 내일 ICN→JFK 일반석 보너스 1편을 골라 마일리지·세금을 계산하고 본인 마일리지 충족 여부 확인
python examples/check_award_quote.py
```

2026-10-27 실제 확인 결과:

- 10월 28일 KE081 10:00 및 KE085 19:40 일반석 보너스 선택 가능. 응답 좌석 수는 각 9.
- KE081 선택 후 운임 계산 성공: 35,000마일 + 442,400원(세금·유류할증료 포함).
- 본인 필요 마일리지 충족 여부 확인 성공. 보유 마일리지 수치는 출력하지 않음.
- 이 도구들은 검색·운임 계산만 수행하며 예약 생성·마일리지 차감·결제를 하지 않음.

### 결제 화면 조사 중간 상태

`experiments/payment_browser.py`는 미완성 Playwright 탐색 도구입니다.
HTTP 로그인 세션을 메모리에서 브라우저로 전달한 뒤, 명령을 받아 화면을 확인합니다.
아이디·비밀번호·브라우저 쿠키·계정 데이터를 파일에 저장하지 않습니다.

```bash
python -m pip install playwright
python -m playwright install chromium
python experiments/payment_browser.py
```

현재 로그인된 마일리지 예매 검색 화면까지 확인했습니다. 항공편 선택 및 결제 화면 도달은
완료하지 못했으며, 대한항공카드/등록 카드 결제 옵션 존재 여부도 아직 확인하지 못했습니다.
탑승객 제출·발권·예약 생성 관련 요청과 결제 변경 요청은 도구에서 차단합니다.
자동으로 결제 직전까지 이동하는 완성된 기능은 아닙니다. 진행 중인 상태를 보존하기 위해 포함했습니다.
