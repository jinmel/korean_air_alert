# 대한항공 보너스 좌석 월별 조회

Python 3.10 이상. 시작 월부터 한국 시간 오늘 + 360일까지 월별로 조회하여
프레스티지석 보너스(O), 일등석 보너스(A)를 출력합니다. 승급(Z 등)은 제외합니다.
공식 사이트의 비로그인 조회 화면에서 발생하는 JSON 요청을 이용하며,
문서화된 공식 외부 공개 API를 사용한 것은 아닙니다.

```bash
python -m pip install -r requirements.txt
python -m playwright install chromium

# 이번 달부터 조회 한도까지, 공항과 첫 조회도 자동 입력
python korean_award.py --origin ICN --destination JFK

# 시작/종료 월 변경 (종료 월도 오늘 + 360일 한도 적용)
python korean_award.py --origin ICN --destination JFK --month 2027-01 --until 2027-03

# 창 없이 실행
python korean_award.py --headless --origin ICN --destination JFK

# 공항 미지정: 열린 브라우저에서 편도, 노선, 시작 월을 직접 선택하고 조회
python korean_award.py --month 2027-01
```

- 노선 하나의 편도 조회입니다. 반대 방향은 공항 코드를 바꾸어 실행하세요.
- `--month` 기본값은 한국 시간 이번 달입니다. 과거 날짜는 출력하지 않습니다.
- `--until` 생략 시 한도까지 조회합니다. `--days`로 일수 한도를 조정할 수 있습니다.
- 미래 월을 시작 월로 선택해도 한도는 실행일 기준입니다.
- 첫 조회는 공식 화면을 이용하고, 이후 같은 브라우저 세션에서 월별 요청을 보냅니다.
- 월별 요청 사이에 2초 간격을 둡니다. 오류나 차단이 있으면 중단하며 재시도하지 않습니다.
- 미인식 응답, 날짜 누락, 다른 월의 응답, 빈 항공편 목록은 조회 실패로 처리합니다.
  따라서 미운항 노선/월도 성공으로 판정하지 못할 수 있습니다.
- 좌석 현황은 공식 화면 안내상 일 1회 업데이트됩니다. 실시간 예약 가능 여부나 좌석 수가 아닙니다.
- CAPTCHA/로그인이 요구되면 수동 브라우저 모드로 확인하세요. 접근 제한을 우회하지 않습니다.
- 쿠키·인증정보·원본 요청 헤더를 파일에 저장하지 않습니다.
- 비공식 요청 구조나 화면이 바뀌면 코드 수정이 필요할 수 있습니다.

## 검증

2026-10-27 한국 시간, 현재 클라우드 환경에서 Chromium으로 실제 조회했습니다.

```bash
python -m unittest -v
python korean_award.py --headless --origin ICN --destination JFK
```

- 단위 테스트 8개 통과: 월말/연도 변경, 날짜 필터, 승급 제외, 미인식 응답 및 잘못된 월 거부.
- 공식 화면에서 일 1회 갱신·향후 360일 제공 안내 확인.
- ICN → JFK, 2026-10-27 ~ 2027-10-22, 13개월 월별 응답 파싱 완료(종료 코드 0).
- 프레스티지 보너스 표시: 2026-10-27 KE081, 2027-10-22 KE081/KE085, 총 3건.
- 시작 월을 2027-01로 변경한 단일 월 조회도 완료했습니다(종료 코드 0).
- UI 자동 입력 중 일시적인 클릭 타임아웃 1회가 있었으며, 재실행에서는 정상 조회했습니다.
  UI 로딩 상태에 따라 실패할 수 있으며 이때 결과를 좌석 없음으로 처리하지 않습니다.
- 위 조회에서 일등석 보너스 표시는 없었습니다. 건수는 좌석 수가 아닙니다.
- 현황 기준 시각: 공식 화면의 2026-10-26 23:00 KST. 이후 좌석은 변경될 수 있습니다.

이 검증은 위 노선 및 실행 시점에 한정됩니다. 다른 노선의 결과나 최종 발권을 보장하지 않습니다.
